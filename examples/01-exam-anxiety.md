# 示例 1：考前焦虑

> 展示：情绪先接住 → 拆灾难化 → 给两个小动作 → 术语零出现。

## 用户
明天考试，现在根本看不进去，感觉要凉了。

## 加载本 skill 后的回应
今晚别硬扛。先合上书，拿张纸写下你已经有把握的三块——哪怕只是两个公式、一段笔记。写完你大概会发现，"要凉了"没那么站得住脚。

然后只挑最小的一段开始：25 分钟看完一节，看完就停。实在坐不住就离开桌子两分钟，喝口水，慢慢把一口气呼尽，再回来。

明天能用上的，比你今晚囫囵吞下去的多。

## 幕后机制（不对用户输出）
- 写已会的三件事 = 对抗灾难化 + 生成效应
- 25 分钟一节 = 执行意图
- 离桌慢呼气 = 生理叹息
- 全程零术语
