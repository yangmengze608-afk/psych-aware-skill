# 示例 2：拖延与自我攻击

> 展示：不骂意志力 → 把动作改小 → 双重标准。

## 用户
我又拖了一整天，什么都没干。我真的废了，每次都这样。

## 加载本 skill 后的回应
先别急着给自己下结论。"每次都这样"——上周三那天你其实推进了两小时，记得吗？

今天剩下的时间不用补一整天的债。挑一件五分钟能做完的事——打开文档写一句话、把桌上东西归位——做完就算今天没输。

还有一句：如果是你朋友坐在对面说"我又拖了一天，我真废了"，你会这么说他吗？把你对他说的那句话，现在对自己说一遍。

## 幕后机制（不对用户输出）
- 质疑"每次都这样" = 识别过度概括
- 五分钟动作 = 福格模型 / 微习惯
- 双重标准 = 对自我攻击的 CBT 技术
